# CMMC Assessment Scripts

Tools for CMMC assessors. Each folder is self-contained and has its own README with setup and usage instructions.

| Folder | What it does |
|---|---|
| `PreAssessment_Checker` | Checks an OSC's pre-assessment package before Phase 2 and the eMASS Pre-Assessment upload (v1.0.0). |
| `eMASS_Checker` | Checks a CMMC Level 2 eMASS Assessment Results workbook before upload (v1.0.0). |
| `CMMC_Evidence_Prefix_Manager` | Aligns evidence filenames to a Document Request List (DRL) and copies them to an output folder with refined names (v1.2). |
| `CMMC_Art_Hash_GUI_App` | Windows Forms app for hashing assessment artifacts (PowerShell). |

To use a tool, download or clone this repository and open the README inside the tool's folder.
